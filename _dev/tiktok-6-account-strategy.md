## Cross-Account Strategy

### Audience Overlap Map
```
DarkMindShorts ←→ UnsolvedScene      (psychology + mystery = natural overlap)
ScriptureSecrets ←→ UnsolvedScene    (biblical mysteries + conspiracy)
NightSceneHorror ←→ UnsolvedScene    (horror + unsolved = creepy overlap)
OneMinuteWisdom ←→ DarkMindShorts    (philosophy + psychology = intellectual)
RedditOnScreen = standalone           (broadest audience, no cross-promo needed)
```

### Cross-Promotion Rules
1. **Never cross-promote in the first 2 weeks** of any account — let TikTok categorize you first
2. Cross-promote via **pinned comments**, not in-video mentions (avoids algorithm confusion)
3. Maximum 1 cross-promo per week per account
4. Only cross-promote between accounts with **overlapping audience** (see map above)

### Account Isolation
- Use **separate email addresses** for each TikTok account
- Use **separate browser profiles** or devices for each login
- Never log into 2+ accounts from the same IP in rapid succession
- Consider a residential proxy rotation if managing from one machine

## Production Pipeline Configuration

### Daily Batch Schedule
| Time | Action | Accounts | Videos |
|------|--------|----------|--------|
| 00:00-04:00 | Auto-generate overnight batch | All | 14-16 |
| 06:00 | QA review + manual filter | All | Remove duds |
| 07:00-23:00 | Scheduled posting (per account slots) | All | Staggered |

### Quality Gates (before posting)
1. **Audio check** — no TTS glitches, pronunciation errors, awkward pauses
2. **Visual check** — no blank frames, text overflow, style inconsistency
3. **Hook check** — first 2 seconds must have a hook (not a title card)
4. **Duration check** — TikTok sweet spots: 31-37s (stickman), 45-60s (cinematic)
5. **Duplicate check** — no identical hook/topic posted to same account within 14 days

## Analytics & Iteration

### Weekly Review Checklist
- [ ] Which **preset style** got the highest completion rate per account?
- [ ] Which **hook template** drove the most views?
- [ ] Which **posting time** had the best engagement?
- [ ] Any videos flagged or suppressed? Adjust content/style
- [ ] Which account is growing fastest? Allocate more volume there

### Kill/Pivot Criteria
If an account hits **any** of these after 30 days, consider pivoting or killing:
- < 200 followers after 30 days of consistent posting
- < 5% average completion rate
- 3+ content moderation flags in a week
- Consistently under 500 views per video

### A/B Testing Priority
1. **Week 1-2:** Test hook styles (question vs statement vs shock)
2. **Week 3-4:** Test posting times (morning vs evening vs late night)
3. **Week 5-6:** Test visual styles (which preset gets highest retention)
4. **Week 7-8:** Test duration (short 35s vs medium 45s vs long 60s)

## Summary: Key Improvements Over Original Plan

1. **Phased launch** — 4 waves over 8 weeks instead of all 6 at once
2. **Full preset mapping** — every account has its complete style rotation documented
3. **Posting schedules with time slots** — not just "3x/day" but when and why
4. **Content pillars per account** — structured rotation prevents topic repetition
5. **Reddit account needs 3 new presets** — 1 preset won't sustain a high-volume account
6. **Cross-promotion rules** — when, how, and between which accounts (with isolation protocol)
7. **Quality gates before posting** — 5-point checklist prevents bad content going live
8. **Kill criteria** — clear metrics to pivot or drop underperforming accounts at 30 days
9. **A/B testing calendar** — structured experimentation instead of random changes
10. **Monetization timeline** — phased from growth-only to Creator Fund to multi-platform
11. **Risk register** — top 6 risks with concrete mitigations
12. **Account isolation protocol** — separate emails, IPs, browser profiles to avoid network detection
