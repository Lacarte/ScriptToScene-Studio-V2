Analyze the entire application for consistency, reliability, and structural correctness. Detect and report any bugs, inconsistencies, missing validations, or architectural weaknesses.

**Do not start coding or modifying the application yet.** First produce a **comprehensive diagnostic report** that includes:

* Identified bugs or potential failure points
* Logical or architectural inconsistencies
* Missing validations, error handling, or safeguards
* Performance or scalability concerns
* Security risks or unsafe patterns
* Maintainability or code quality issues

For each issue found, include:

* A clear description of the problem
* The affected module, component, or file
* The severity level (low, medium, high, critical)
* The potential impact on the system
* A recommended fix or improvement

After presenting the report, propose a **prioritized improvement plan** outlining what should be fixed first to maximize stability, reliability, and long-term maintainability. Do not implement any fixes until the report has been reviewed and approved.
